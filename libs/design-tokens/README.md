# design-tokens

The ASYS design tokens, shared by the PWA and the site.

- `src/tokens.json`: every token (colours for Light, Dark and Voice only, type, spacing, radii, shadow, sizes), copied from the ASYS design system artifact, which stays the source of truth.
- `src/palettes.json`: the curated palettes for the Palette setting, generated by `node scripts/palettes.mts` from `tokens.json`. Do not edit it by hand; CI fails when it is stale.

To add a palette, add its inputs to `PALETTES` in `scripts/palettes.mts`, run the script, and copy the new `palettes.json` back into the design system artifact.
